# Sipalaya Course Showcase

A responsive, modern React application that displays available courses in an interactive card layout built with **Tailwind CSS** and **Lucide React** icons.

## Features

- 🎨 **Modern Card Design**: Custom-styled card layout with hover animations, badges, and status tags.
- 📱 **Fully Responsive Layout**: Uses a dynamic CSS Grid setup (1 column on mobile, 2 on tablet, and 3 on desktop).
- 🔗 **Direct Enrollment Links**: Dynamic navigation opening course links in new tabs using standard security practices (`noopener, noreferrer`).
- ⏱️ **Course Metadata**: Integrated duration badges and medium indicators (Online, Hybrid, Physical).

## Tech Stack

- **Framework**: [React.js](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
